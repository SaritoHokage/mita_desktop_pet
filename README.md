# mita_desktop_pet
Мита — десктоп‑ассистент с голосом и UI
Мита — это локальный десктоп‑ассистент с поддержкой голосового ввода/вывода, горячих клавиш и удобного графического интерфейса на Python, ориентированный на быструю реакцию и приватность без обязательной облачной зависимости. Проект создан как pet‑приложение с упором на русскоязычный сценарий, офлайн‑TTS/ASR по возможности и расширяемую архитектуру команд.

Возможности
Голосовой ввод и текстовые команды, быстрая активация по горячей клавише и кнопке в UI.

Голосовой ответ через выбранный движок TTS (поддержка pyttsx3, Coqui XTTS/XTTS‑v2 и др.) с возможностью заменить TTS на готовые аудиофайлы.

Графический интерфейс на PySide6/PyQt6: панель диалога, статус движков, индикатор записи, настройки устройств и голоса.

Локальная обработка по максимуму: приватность и предсказуемые задержки, без обязательных внешних API.

Плагины/команды: шаблон для добавления своих действий (системные операции, поиск, заметки, запуск программ).

Демонстрация
Скриншоты: см. папку screenshots/ в репозитории (если нет — добавь два: главный экран и окно настроек).

Короткое видео‑демо: положи mp4 в папку demo/ и упомяни здесь ссылкой относительного пути.

Стек и требования
Python 3.10+ на Windows (тестировалось на Win10/11, PowerShell).

GUI: PySide6 или PyQt6 (по умолчанию PySide6).

Аудио: pyaudio/sounddevice или аналог для записи/воспроизведения; рекомендованы виртуальные окружения.

TTS: pyttsx3 (офлайн) или Coqui TTS/XTTS; поддержка переключения в настройках.

Опционально: VAD/ASR движки по желанию (например, Silero VAD, Vosk/Whisper локально).

Установка
Клонирование

git clone <repo_url>

cd mita-desktop (замени на фактическую папку).

Виртуальное окружение

py -3.10 -m venv .venv

..venv\Scripts\Activate.ps1 (PowerShell).

Зависимости

pip install -U pip wheel

pip install -r requirements.txt (подготовь файл; см. раздел «Зависимости»).

Проверка аудио

Убедись, что микрофон и динамики выбраны в настройках Windows; при необходимости установи порт-аудио драйверы.

Быстрый старт
Вариант с GUI:

python -m app.main_gui или python app/main_gui.py (замени на актуальный путь).

Вариант без GUI (консоль):

python -m app.cli или python app/cli.py.

По умолчанию активируется офлайн‑TTS; переключение на другой движок в settings.yaml/в UI.

Конфигурация
settings.yaml в корне проекта или в app/config/ (укажи фактический путь):

ui.backend: pyside6 | pyqt6

audio.input_device / audio.output_device

tts.engine: pyttsx3 | coqui_xtts | file_player

tts.voice: ru | en | custom

hotkey: например, Ctrl+Shift+Space

asr.engine: vosk | whisper | disabled .

Персональные ключи API не требуются для офлайн‑режима; для облачных сервисов добавь .env с переменными.

Структура проекта
app/ — исходники приложения:

ui/ — окна, диалоги, элементы интерфейса (PySide6/PyQt6).

audio/ — ввод/вывод, VAD, управление потоками.

tts/ — абстракции и адаптеры под движки (pyttsx3, XTTS, file).

asr/ — распознавание речи локально/облако (опционально).

skills/ — команды/плагины ассистента с простым интерфейсом расширения.

core/ — маршрутизация команд, состояние сессии, конфиги.

scripts/ — утилиты запуска и сборки.

resources/ — голоса, звуки, иконки.

tests/ — базовые тесты модулей.

(Подгони под фактические папки репозитория.)

Зависимости (примерный список)
PySide6 или PyQt6 для UI.

pyttsx3 или coqui‑TTS/XTTS для синтеза.

pyaudio или sounddevice для работы с аудио.

pydub, numpy — обработка звука; PyYAML — конфиги.

opcional: vosk/whisper, silero‑vad для ASR/VAD.

Сформируй точный requirements.txt из текущей версии проекта.

Горячие клавиши
Глобальная активация записи: настраиваемая (например, Ctrl+Shift+Space).

Остановка/отмена воспроизведения: Esc в окне приложения.

Переключение TTS‑голоса: через меню Настройки или быстрый селектор в статус‑баре.

Расширение командами
Каждая команда — класс с методом handle(text/context) и декларацией триггеров.

Помести модуль в app/skills/, добавь импорт в реестр, команда появится в списке в UI.

Примеры:

Системные: «открой калькулятор», «покажи папку загрузок».

Заметки: «запомни…», «напомни…».

Поиск: «найди…» с выбором источника.
